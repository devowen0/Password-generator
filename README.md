# Password-generator
URL to the Password generator page: https://access-secure-passwords.netlify.app/

## Improvements
I made some changes to improve the UX/UI in this, including:
- Made it formatted well on both desktop and mobile.
- Added a sliding scale for number of characters
- Added gradient backgrounds for both light and dark mode
- Added svg icons for toggling between dark and light mode
- Added rounder corners to many elements, in order to improve feelings of trust and make the UI more modern
- Added a 'strength bar' on the bottom, which tells how strong the password is
- Allows the user to make the password be anywhere from 4-64 characters
- Allows the user to determine whether they want numbers or special characters in their password
- Has a copy icon that allows the user to easily copy a password that is generated
- Added white box background to wrap around the elements, to more easily separate them from the gradient background for contrast
- Reassure users by telling them when their password is strong enough
- Increases trust through polished UI and reassurance
- Has more focus on main password that is generated, with keeping it in a round box
- Better alignment of elements
- Split characters into logical groups in javascript (letters, numbers, symbols)
- Added 'Regenerate' button to allow user to regenerate password
- Auto-updates password when boxes are checked or unchecked
- Uses reactive logic on password generation
